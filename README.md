# CNC Machine
This is a machine which can write, draw etc. automatically 
## COMPONENTS REQUIRED
<ol type="1">
  <li>Stepper Motors</li>
  <li>ULN2003 Stepper Motor Driver Board</li>
  <li>Jumper Wires(Male to Female)</li>
  <li>Arduino Uno</li>
  <li>Breadboard</li>
  <li>Power Resource</li>
</ol>
